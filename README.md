# CubeReach demonstration: derived data snapshot

This repository holds the derived, pseudonymised datasets behind the Demonstration section (Section 4.3) of the CubeReach report by Tommy Kiprillis (FIT5145 Foundations of Data Science, Monash University, Semester 2 2026). They come from the World Cube Association (WCA) results export and developer database export of 13 October 2026.

* **Data and data dictionary:** [`data_snapshot/`](data_snapshot/). Start with [`data_snapshot/README.md`](data_snapshot/README.md).
* **Download:** use **Code > Download ZIP** on this page, or open any CSV file and choose **Download raw file**.
* **Reproduction:** the R Markdown file submitted with the report reads these files directly from this repository.

The official exports change every few days and the WCA deletes old ones, so this snapshot preserves the exact data used.

This information is based on competition results owned and maintained by the World Cube Association, published at https://worldcubeassociation.org/results as of 13 October 2026.
